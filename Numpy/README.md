## 🔢 NumPy

This repository contains a Jupyter Notebook (NumPy exercises.ipynb) with practice problems and solutions for learning **NumPy**.
The notebook includes topics related to Numpy, fundamental Python library for numerical computing

## 📌 Features Learned 

- *Array Creation:*
  - zeros 
  - ones  
  - arange 
  - identity 
  - random
    
- *Array Indexing & Slicing:*  
  - First element, last element  
  - Odd/even positions  
  - Reverse order  
  - Submatrices

- *Array Manipulation:*  
  - Reshape  
  - Sorting  
  - Type conversion  
  - Element updates

- *Boolean Masks & Conditional Selection:*
  - Filtering negative values  
  - Values greater than mean  
  - Specific value selection

- *Logic Functions:*  
  - any()  
  - all() 

- *Summary Statistics:*  
  - Sum  
  - Mean  
  - Max  
  - Column & row operations

## 🛠️ Tech Stack

- Python 3
- Jupyter Notebook
- NumPy
