## 📊 Matplotlib Visualizations

This repository contains a Jupyter Notebook (Matplotlib.ipynb) that demonstrates different visualization techniques using **Matplotlib**, along with NumPy and Pandas.  
It’s part of my learning journey in **Python Data Science**.

---

## 🎨 Key Learnings
- Line plots with NumPy
- Pandas integration (`df.plot`)
- Styling plots (figure size, labels, titles)
- Inline visualization with Jupyter Notebook (%matplotlib inline)
- Customizing graphs (axes, titles, labels)

---

## 🛠️ Tools Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
