# 🐼 Pandas 

This repository demonstrates my **hands-on learning** of Pandas, one of the most important Python libraries for Machine Learning.

---

## 📌 Features Learned 

- **Pandas Basics**  
  - Reading CSV files with `pd.read_csv()`
  - Exploring DataFrames with `.head()` and `.tail()`
  - Handling headers, missing values, and whitespaces
  - Simple plotting with `matplotlib`  

- **Pandas Series**  
  - Creating `Series` from lists  
  - Naming and documenting Series  
  - Accessing values and dtype  
  - Series as numpy arrays  
  - Series index and dict-like behavior
  - Conditional Selection (Boolean array)

- **Pandas DataFrames**  
  - Creating DataFrames from dictionaries  
  - Adding Columns, changing index and dropping columns
  - DataFrame selection, slicing and indexation
  - Boolean masking
  - DataFrame summary statistics
  - Viewing and exploring tabular data with matplotlib
